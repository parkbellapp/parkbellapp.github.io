# ParkBell

ParkBell is an Android app that reminds you to pay for parking after your phone disconnects from your car Bluetooth.

Website: https://parkbellapp.github.io

## Features

- Parking reminder after car Bluetooth disconnect
- Optional GPS paid-parking filter
- Local parking tile checks
- Parking app shortcut
- Snooze reminder action
- Parking exclusions by address or postal code
- English, Dutch, and Russian UI

## Privacy

ParkBell stores app settings locally on your device. Exact GPS coordinates are not sent to ParkBell servers.

Read the full privacy policy:

https://parkbellapp.github.io/privacy.html
